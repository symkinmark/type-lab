# Type Lab

A single-file font specimen workbench — browse all Google Fonts, upload your own
(incl. Adobe files), test custom words in caps/lowercase/bold across Latin, Cyrillic
(Ukrainian), Hebrew, Portuguese & German, compare faces side by side, get an instant
"insight" analysis of each font, and organise with favourites, project boards, an
archive and per-font licence notes.

## Run it
Just open `index.html` — it's fully self-contained. Hosted here via GitHub Pages.

## Memory / sync
Favourites, boards, archive and licence notes save in your browser automatically.
For cross-device memory, open the ⚙ **sync** panel and connect a free JSONBin bin
(or your own GET/PUT JSON endpoint).

## Notes
- Google Fonts load lazily as you scroll; needs an internet connection.
- Uploaded fonts work fully offline.
